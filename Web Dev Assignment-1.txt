##### **1. Explain the difference between frontend, backend, and full-stack development with suitable real-world examples.**



* ***Frontend Development (Client-Side):***

It deals with everything users see and interact with on a website — layout, colors, buttons, and animations.

Technologies: HTML, CSS, JavaScript, React, Angular

Example: The home page design and product grid on Amazon.



* ***Backend Development (Server-Side):***

It handles the logic, database, and server communication that run behind the scenes.

Technologies: Java, Python, Node.js, PHP, MySQL

Example: When you log into Facebook, the backend verifies your credentials and fetches your data.



* ***Full-Stack Development:***

It involves both frontend and backend development. A full-stack developer builds the entire web app — from UI to database.

Example: A developer who builds both the UI and server logic for a food delivery app.

##### **3. Describe how a browser requests and displays a web page from a web server.**



1. The user enters a URL (e.g., www.google.com).
2. The browser sends an HTTP request to the web server.
3. The DNS converts the domain name into an IP address.
4. The web server finds the requested page and sends back HTML, CSS, and JS files.
5. The browser renders these files — HTML for structure, CSS for design, and JS for interactivity — and displays the web page.

##### **5. Explain what a web server is and give examples of commonly used servers.**



A Web Server is software or hardware that stores, processes, and delivers web pages to clients through HTTP/HTTPS.

It receives requests from browsers and responds with the requested web pages or data**.**



###### ***Examples of Common Web Servers:***

* Apache HTTP Server
* Nginx
* Microsoft IIS
* LiteSpeed
* Node.js (Express server)
